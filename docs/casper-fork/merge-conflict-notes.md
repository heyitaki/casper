# Merge conflict notes

Upstream files touched by fork patches that tend to drift upstream. Re-check each when running `git merge upstream/main`. The authoritative per-patch file lists live in each patch doc ([index](../casper-fork.md)); this file carries merge-time *advice* plus a file→patch cross-reference. Grep `// CASPER:` for the in-tree hunk list.

## Files with merge advice

- `Sources/ContentView.swift` — **heaviest conflict surface** ([minimal-mode sidebar](minimal-mode-sidebar.md), [compact sidebar](compact-sidebar.md), [session navigation](sidebar-session-navigation.md), [group selection](sidebar-group-selection.md), [archive](session-archive.md), [footer](sidebar-footer.md), [fork conversation](fork-conversation.md)). Upstream's sidebar render pipeline (`SidebarWorkspaceRenderItem`, `SidebarDragState`) is the base; Casper layers sort/filter/compact-row on top. Never reintroduce preference-key→@State writes (livelock class #2586/#5708). If upstream refactors sidebar layout, hidden-sidebar gap handling, or titlebar padding math, expect non-trivial manual conflict resolution.
- `Sources/TerminalWindowPortal.swift`, `Sources/BrowserWindowPortal.swift` — [minimal-mode](minimal-mode-sidebar.md) pass-through bands + [debug-log gating](debug-log-gating.md). **Typing-latency hot path** — preserve the pointer-event guard (upstream's `WindowInputRoutingContext.allowsPortalPointerHitTesting` is the semantically equivalent successor to the manual `isPointerEvent` check) and the interior-point early-reject.
- `Sources/AppDelegate.swift` — touched by [minimal-mode sidebar](minimal-mode-sidebar.md) (reveal handlers, `cmux_sendEvent` intercept), [panel context menu](panel-context-menu.md), [startup warmup](startup-agent-warmup.md) (two one-line hooks), [group selection](sidebar-group-selection.md) (⌘1…9 gate, ⌘W route, group-mode clear in the global key handler), [archive](session-archive.md) (autosave fingerprint), [activation-desync repair](activation-and-first-mouse.md#activation-desync-repair), [hang watchdog](hang-watchdog.md), and a [small hunk](small-casper-hunks.md) (`isModalOrSheetPresented`). Many independent regions — resolve hunk by hunk, not wholesale.
- `Sources/TabManager.swift` — `moveTabToTopForNotification` bumps within the workspace's repo group ([compact sidebar](compact-sidebar.md)); stock cmux unconditionally bumps to global top of unpinned. Empty-window gates in `closeWorkspace` (`guard … || tabs.count > 1`, `selectedTabId = nil` on empty), `closeWorkspaceIfRunningProcess`, `closePanelAfterChildExited`, plus the `casperGroupSelectionActive` clear at the top of `focusTab` ([group selection](sidebar-group-selection.md)) — re-check if upstream reworks the workspace-close or focus paths. `restoreSessionSnapshot` calls `pruneMissingAcrossMainWindows` after `tabs` is live ([archive](session-archive.md)) — re-check if upstream reworks session restore.
- `Sources/Workspace.swift` — a reopen-last-closed patch here was retired in the 2026-07 merge, but the file is still live: [bonsplit `tabBarVisibility`](fork-infrastructure.md#bonsplit-tab-bar-visibility), the [compact-sidebar](compact-sidebar.md) focus publisher, the [`appendLog` seam](small-casper-hunks.md), the [archive](session-archive.md) snapshot write/re-register, and the [fork-conversation](fork-conversation.md) panel-ID entry point. **Do not assume this file is untouched.**
- `Sources/RestorableAgentSession.swift` — the fork-session patch was retired in the 2026-07 merge (upstream's own `forkShellCommand` superseded it), but the file is still live via the [small hunk](small-casper-hunks.md) (`freshLaunchShellCommand` + orphan-transcript resume fallback). Do not assume untouched.
- `Sources/GhosttyTerminalView.swift` — high-traffic: [panel context menu](panel-context-menu.md) (rightMouseDown under mouse capture), [bonsplit New Tab item](fork-infrastructure.md#bonsplit-tab-bar-visibility), the fish `XDG_DATA_DIRS` injection ([agent-resume shell integration](agent-resume-shell-integration.md)), the [group-selection](sidebar-group-selection.md) `mouseDown` clear, the [archive](session-archive.md) `keyDown` submit hook, and [debug-log gating](debug-log-gating.md) in `forceRefresh`. Re-validate each region after upstream merges.
- `Sources/App/DebugLogging.swift` — the entire `MainThreadHangWatchdog` type is Casper-only ([hang watchdog](hang-watchdog.md)); upstream's copy of this file is just the `cmuxDebugLog` shim, so any upstream edit there conflicts against the whole class.
- `Sources/KeyboardShortcutSettings.swift`, `Sources/KeyboardShortcutContext.swift` — 4 nav actions + `.nonBrowserPanel` context + `casperEventEditsTextInput` ([session navigation](sidebar-session-navigation.md)). If upstream adds arrow-key actions, re-check default-shortcut collisions.
- `Sources/FileExplorerSearchController.swift`, `Sources/SessionIndexStore.swift` — [bundled ripgrep](bundled-ripgrep.md) + [find ranking](find-ranking.md). **Keep ONE rg resolution mechanism** (upstream's `RipgrepExecutableResolver` with the bundle-first candidate); do not let either site reintroduce its own fallback list.
- `Sources/SessionPersistence.swift` — [archive](session-archive.md) (`SessionPanelSnapshot.archived: Bool?`) + the [ZDOTDIR re-entry hoist](agent-resume-shell-integration.md#resume-launcher-zdotdir-re-entry). Re-validate if upstream changes the panel snapshot shape or the resume launcher script builder.
- `cmux.xcodeproj/project.pbxproj` — Casper file registrations + ripgrep build phases; objectVersion 60. Conflicts are mechanical but always require manual resolution.
- `Resources/Localizable.xcstrings` — fork keys from several patches; **xcstrings JSON merges poorly** — expect to redo string additions by hand if upstream touches the same strings.
- `.github/workflows/*`, `scripts/ensure-ghosttykit.sh`, `.gitmodules` — heyitaki URLs + xcframework flavor tags ([fork infrastructure](fork-infrastructure.md), [bundled ripgrep](bundled-ripgrep.md)).
- `.github/swift-file-length-budget.tsv` — fork-grown files carry bumped budgets; upstream will not have these numbers.
